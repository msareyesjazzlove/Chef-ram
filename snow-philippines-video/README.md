# What If the Philippines Had Snow for a Whole Year? (3D animated, 1:30)

`philippines-snow-year-3d.mp4` is a 1280×720, 30fps, 90-second 3D animated video with a music and ambient soundtrack.

## Scenes
| Time | Scene |
|---|---|
| 0:00 | Title: a sunny tropical island |
| 0:10 | Day 1: 32°C → −5°C, the first snow |
| 0:20 | Snow-covered beaches, frozen sea, bangkas stuck in ice |
| 0:32 | Barangay life: snowy jeepneys, kids' first snowman |
| 0:45 | The rice terraces freeze |
| 0:57 | Chocolate Hills become "Vanilla Hills" (ski resort) |
| 1:08 | A white Christmas with glowing parols |
| 1:20 | The sun returns: "Mabuhay, Pilipinas!" |

## Re-rendering
`source/` holds the Three.js scene (`scene.js`), the frame renderer (`render.js`, which uses Playwright and ffmpeg) and the soundtrack generator (`audio.py`).
